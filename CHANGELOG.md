All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-14

### Added

- Initial release.
- Integrations **Community** section for bbPress; **Content** for Co-Authors Plus.
- Distinct SEO stack descriptions (Rank Math, Yoast, All in One SEO, SEOPress).
- Modal Modals tab with `[aegis_modal]` shortcode and `aegis/modal-*` starter patterns.
- Hooks admin lists locations and instances; hook pattern CPT create/render requires Pro (Add New → License).
- Repository tooling: `composer.json` / `phpcs.xml`, GitHub Actions (CI, release, spelling, stale), `.distignore` + `.gitattributes` export-ignore for release zips.
