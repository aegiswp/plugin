# Integrations Dashboard

Manage third-party plugin compatibility from **Aegis → Integrations** (`admin.php?page=aegis-integrations`).

Plugins are grouped by category in the sidebar (alphabetical). Each plugin’s enable toggle, extras, and block-condition switches sit in that category as a flat settings list (same row layout as **Blocks**). Stack headers and toggle rows use brand SVG marks when available (WooCommerce, Easy Digital Downloads, AffiliateWP, ACF, bbPress, Fluent Forms/Booking, Rank Math, Sensei LMS); otherwise dashicons. Stacked plugins in a category are listed alphabetically. Integrations are **off by default** on new installs, and a toggle can only be turned on when that plugin is installed and active. A one-time migration writes leftover stored ons to off when that plugin is not active, so installing the plugin later does not turn the integration on by itself. Admin notices remind you when a supported plugin is installed but its integration is disabled.

**Enable All** on a category turns on installed plugins first, then their extras. **Disable All** turns the plugins off and locks extras again. Extras stay disabled unless the plugin is active **and** the parent integration is on. **Author Schema** under Co-Authors Plus is skipped by Enable All (so Yoast/Rank Math author markup is not duplicated by accident). Disable All still turns it off.

Service credentials (BunnyCDN, Google Maps, analytics providers) live at **Aegis → Connectors**. See [[connectors]].

**FluentCRM** is on **CRM** with WP Fusion (`#fluent-crm` still opens that category). The FluentCRM toggle has no extras of its own. With **Aegis Pro**, it gates `core/video` FluentCRM automation (funnels, tags, and lists on play / milestone / complete). The shared video tracker loads from the FluentCRM module when that extra is on a rendered video — LearnDash does not need to be enabled. Events run only for logged-in FluentCRM contacts. Funnel, tag, and list IDs are read from the saved block on a **published post** (not the request body) and started with FluentCRM `FunnelProcessor`. The extra must live in post content so REST can find it — template-part-only videos are skipped. Contacts already in a funnel are skipped unless that funnel allows `run_multiple`. See [[../../aegis-pro/docs/features/video-stack#lms-and-fluentcrm|Video Stack — LMS and FluentCRM]].

**WP Fusion** (or WP Fusion Lite) is the other CRM toggle. Detection is `WPFusion::is_plugin_active()` (`WP_FUSION_VERSION` or `wpf_has_tag()`). There is no framework CSS. **CRM Tags** and **CRM Lists** extras sit under that toggle. Tags add has / has all / has not rules (has-all uses catalog tokens). Lists add has / has not list rules and check CRM list membership (`get_contact_lists()`, FluentCRM lists, Mailchimp default audience) rather than treating lists as tags. Either extra also enables **Is logged in (CRM)** / Smart Logic **WP Fusion Logged-in (CRM)** (`wpf_is_user_logged_in()`, including auto-login). Pickers use `available_tags` / `available_lists` (Mailchimp falls back to `mc_lists`), not `wpf_get_tags()`. A stored ID missing from the catalog still appears as **(saved)**. An empty Has value matches nobody; an empty Does not have value matches everyone, same as an empty user role. See [[../../aegis-pro/docs/features/query-conditions#wp-fusion|Query Conditions — WP Fusion]] and [[conditional-logic#smart-logic|Smart Logic]].

**SEO Plugins** are on **SEO** (`#seo` opens that category), covering **Rank Math**, **Yoast SEO**, **All in One SEO**, and **SEOPress**. Each integration provides:
- **Schema delegation**: Suppresses built-in FAQ, Event, Local Business, and Video JSON-LD markup on Aegis blocks so the active SEO plugin serves as the canonical schema provider without duplicate markup.
- **Video Sitemap (Pro)**: Delegates video indexing to the active SEO plugin's sitemap engine via `Video\Seo\VideoSitemapManager` when `seo_video_sitemap` is enabled.
- **Breadcrumbs**: Aegis natively supports and styles the WordPress Core Breadcrumbs block (`core/breadcrumbs`) using theme design system tokens. Rank Math’s `.rank-math-breadcrumb`, SEOPress’s `.seopress-breadcrumbs`, and Yoast’s `#breadcrumbs` / `.yoast-breadcrumbs` trails share the same stylesheet when present; separators use each plugin’s own markup (Rank Math `.separator`, SEOPress `.breadcrumb-sep`; Yoast keeps nested-span text separators and `.breadcrumb_last` — theme CSS does not force flex layout on Yoast wrappers) so configured separator characters are not overridden. The active SEO plugin outputs its own `BreadcrumbList` schema graph in JSON-LD.
- **Fallback Description**: Pro suppresses its fallback meta description when an SEO plugin is detected.

Detection methods:
- **All in One SEO**: `AllInOneSEO::is_plugin_active()` (`AIOSEO_VERSION`, `class_exists( 'AIOSEO\Plugin\AIOSEO' )`, `function_exists( 'aioseo' )`, or `defined( 'AIOSEO_FILE' )`). Installed-but-inactive uses `all-in-one-seo-pack/all_in_one_seo_pack.php` or `all-in-one-seo-pack-pro/all_in_one_seo_pack.php`. Schema filtered via `Seo\AioseoAdapter` (`aioseo_schema_output`).
- **Rank Math**: `RankMath::is_plugin_active()` (`RANK_MATH_VERSION`, `class_exists( 'RankMath' )`, `function_exists( 'rank_math' )`, `defined( 'RANK_MATH_FILE' )`, `defined( 'RANK_MATH_PRO_VERSION' )`, or `defined( 'RANK_MATH_PRO_FILE' )`). Installed-but-inactive uses `seo-by-rank-math/rank-math.php` or `seo-by-rank-math-pro/rank-math-pro.php`. Schema filtered via `Seo\RankMathAdapter` (`rank_math/json_ld` → `aegis_rank_math_json_ld`). Pro video sitemap uses `Video\Seo\RankMathVideoSitemap`.
- **Yoast SEO**: `Yoast::is_plugin_active()` (`WPSEO_VERSION`, `WPSEO_FILE`, `WPSEO_Options`, `YoastSEO()`, `yoast_breadcrumb()`, Premium `WPSEO_PREMIUM_FILE` / `WPSEO_Premium`, or Video SEO `WPSEO_VIDEO_FILE` / `WPSEO_Video_Sitemap`); Premium and Video SEO also expose `Yoast::is_premium_active()` / `Yoast::is_video_seo_active()`. Installed-but-inactive uses `wordpress-seo/wp-seo.php` or `wordpress-seo-premium/wp-seo-premium.php`. Schema filtered via `Seo\Adapters\YoastAdapter` (`wpseo_schema_graph` → `aegis_yoast_schema_graph`). Theme styles `#breadcrumbs` / `.yoast-breadcrumbs` (current crumb `.breadcrumb_last`; no forced flex). Pro video sitemap uses `Video\Seo\YoastVideoSitemap` (Video SEO–gated `wpseo_video_index_content` / duration-only `wpseo_video_item`; fill-empty `VideoObject` enrichment on `wpseo_schema_graph` at priority 25, appending nodes for additional videos).
- **SEOPress**: `SEOPress::is_plugin_active()` (`SEOPRESS_VERSION`, `SEOPRESS_PLUGIN_DIR_PATH`, `SEOPRESS_PRO_VERSION`, `SEOPRESS_PRO_PLUGIN_DIR_PATH`, or `function_exists( 'seopress_get_service' )`); Pro-only features also check `SEOPress::is_pro_active()` (`SEOPRESS_PRO_VERSION`, `SEOPRESS_PRO_PLUGIN_DIR_PATH`, or `seopress_pro_get_service()`). Installed-but-inactive uses `wp-seopress/seopress.php` or `wp-seopress-pro/seopress-pro.php`. Schema filtered via `Seo\Adapters\SeopressAdapter` named methods on SEOPress automatic schema hooks (`seopress_schemas_auto_faq_json`, `seopress_schemas_auto_event_json`, `seopress_schemas_auto_lb_json`, `seopress_schemas_auto_video_json` → `aegis_seopress_schemas_auto_schema` with `$type` `faq` / `event` / `local_business` / `video`). Pro video sitemap uses `Video\Seo\SeopressVideoSitemap` (`seopress_pro_video_sitemap_builder_content` when Pro is active; automatic Video schema enrichment on `seopress_schemas_auto_video_json` at priority 25).

See [[seo-schema-delegation]] and [[../../aegis-pro/docs/features/video-stack|Video Stack]].

## Schema Delegation

When an SEO plugin integration is enabled, you can delegate FAQ, Event, Local Business, and Video schema to that plugin instead of built-in block markup. See [[seo-schema-delegation]].

Video sitemap delegation requires **Aegis Pro**.

## Pattern Control (Pro)

Several integrations include **Pro** sub-toggles to hide third-party block patterns (WooCommerce, LearnDash, LifterLMS, Sensei, Fluent Forms, Fluent Booking, Co-Authors Plus). Pro [[../../aegis-pro/docs/features/pattern-control|Pattern Control]] reads the WooCommerce/LMS/forms options; Co-Authors Plus Patterns are applied from Pro `CoAuthorsPlus`. **Reset Defaults** on **Integrations** clears `aegis_integrations` and `aegis_pattern_control`. **Reset Defaults** on **Connectors** only resets Connectors-owned toggles (BunnyCDN, Maps), their credentials, and `aegis_analytics` — it does not wipe other Integrations toggles or pattern control. The global settings export does not include `aegis_pattern_control`.
